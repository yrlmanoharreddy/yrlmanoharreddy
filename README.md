## Featured projects

### [mcp-multi-tool-assistant](https://github.com/yrlmanoharreddy/mcp-multi-tool-assistant)

An agentic assistant built on the Model Context Protocol that exposes multiple tools through FastMCP and lets an LLM plan and call them autonomously, using Groq-hosted models via LangChain.

### [rag-system-langchain](https://github.com/yrlmanoharreddy/rag-system-langchain)

A retrieval-augmented generation pipeline over local PDF documents, using LangChain, a Chroma vector store, HuggingFace embeddings, and Groq's Llama 3.3 for retrieval-grounded question answering.

### [llm-provider-gateway](https://github.com/yrlmanoharreddy/llm-provider-gateway)

A FastAPI gateway that provides a unified interface across multiple LLM providers, including Groq, Gemini, and Ollama, so downstream applications can switch providers without changing client code.

### [agentic-flight-booking-langgraph](https://github.com/yrlmanoharreddy/agentic-flight-booking-langgraph)

A stateful flight reservation workflow built with LangGraph and ChatGroq, modeling multi-step booking logic as a graph of nodes sharing a typed state object.

### [spring-boot-microservices-banking](https://github.com/yrlmanoharreddy/spring-boot-microservices-banking)

A multi-module Spring Boot microservices platform for accounts, cards, and loans, with PostgreSQL, JPA, validation, global exception handling, Swagger/OpenAPI documentation, and a Spring Cloud Config Server.

### [dockerops-agent-langchain](https://github.com/yrlmanoharreddy/dockerops-agent-langchain)

A LangChain agent that manages Docker operations through tool calling, connecting an LLM to real container lifecycle actions rather than just answering questions about them.
